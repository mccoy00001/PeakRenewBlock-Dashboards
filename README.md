# Peak RenewBlock
**Peak RenewBlock** aims to combine blockchain and solar power analytics to provide cutting-edge tools for renewable energy monitoring, reporting, and transparency.
## Key Features
-   **Blockchain Transparency**: Track renewable energy production using immutable data.
-   **Tokenized Carbon Credits**: Monitor and report on carbon offsets and compliance with ease.
-   **Solar Data Dashboards**: Provide insights into performance, ROI, and energy impact for councils and private clients.
## Current Focus
- Building
SQL dashboards through **Dune Analytics** for:
1.    SolarCoin transaction tracking.
2.    Energy Web Token impact data.
3.    Tokenized carbon credit systems.
